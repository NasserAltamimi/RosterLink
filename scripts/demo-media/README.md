# Night Circuit demo media

The seed copies these assets into local post storage. The fictional captions, rank card, reactions, and discussions are demo content.

- **Rocket League.** Jonalotu recorded the 3v3 match on PlayStation 5 and marked the recording Public Domain Mark 1.0. `rotation.mp4` is a silent 12-second excerpt, and `rotation.jpg`, `score.webp`, and `podium.webp` are frames from the recording. `rank.webp` adds an original fictional session card to a match still. The rank is player-shared demo content. Rocket League belongs to Psyonix. [Original recording](https://archive.org/details/rocket-league_gameplay) · [Public Domain Mark](https://creativecommons.org/publicdomain/mark/1.0/)
- **OpenArena.** Draena recorded the Aerowalk duel against Wolf-Snipe on January 8, 2022. The local video excerpts and stills are cropped, resized, and distributed under the recording’s CC BY-SA 4.0 license. Audio was removed from the excerpts. [Original recording](https://archive.org/details/Openarena-Ratmod-Duel-Wolf-Snipe-vs-Draena-Aerowalk-2022_01_08) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
